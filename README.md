<h2>System Requirements</h2>

Kite Browser supports macOS Big Sur 11+.

<h2>Features</h2>

Kite is an AI-powered browser with three focus modes:
- Shopping Mode
- Business Mode
- Personal Mode

You can customise the accent colour of existing modes and create new focus modes through Settings.

<h2>Known Limitations</h2>

AI assistant doesn't work right now since it needs a valid API key from Anthropic. AI functionality will be enabled by the production release.

You can't sign in to Kite for now. Sign-in functionality will be available in the production release.

<h2>Security Warning</h2>

You might see warnings stating:

"This app can't be opened because it was downloaded from the Internet."

To fix this, Open Terminal, type sudo xattr -cr and drag Kite from your downloads folder to your terminal window and press Return, type your password and go to your downloads folder and open Kite
